= Ammitto Türkiye asset-freeze data

image:https://github.com/ammitto/data-tr/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-tr/actions/workflows/fetch.yml"]

This repository stores Türkiye's asset-freeze list D under Articles 3.A and
3.B of Law No. 7262 as YAML for Ammitto. The records in `processed/` cover
individuals, entities and organisations listed by the Ministry of Treasury
and Finance to counter the financing of the proliferation of weapons of mass
destruction.

== Source

* Publisher: Ministry of Treasury and Finance of the Republic of Türkiye
* List page: https://en.hmb.gov.tr/3a3b
* File downloaded (list D, Excel): https://ms.hmb.gov.tr/uploads/sites/2/2025/10/D-7262-SAYILI-KANUN-3.A-VE-3.B-MADDELERI-EXCEL-ce85ee0d2c57738a.xlsx

The list page gives each Presidential decision behind the list, with its
Official Gazette issue.

== Contents

`processed/` holds one file per listing, mostly named after its reference
number (`processed/tr-100.yaml`); a listing without one is named after the
name instead (`processed/tr-amir-rahimi.yaml`), as is one whose reference
number the list gives twice.

`processed/_index.yaml` lists every file, with the time of the last fetch.

Dates the sheet stores as dates are written as `YYYY-MM-DD`; other values are kept as published, and notes, text dates and nationalities are in Turkish.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `name` | string | Name of the person or organisation
| `entity_type` | string | `person` or `organization`
| `program` | string | The legal basis, `Law No. 7262, Articles 3.A/3.B`
| `reference_number` | string | Reference number in the list, where given
| `listed_date` | string | Listing date, sometimes with notes on later amendments; check against the source, as a few values are not dates
| `official_gazette` | string | Date and number of the Official Gazette issue that carried the listing
| `decision_number` | string | Date and number of the decision that ordered it, where given
| `nationality` | string | Nationality, in Turkish (such as `İRAN`)
| `date_of_birth` | string | Persons: date of birth
| `place_of_birth` | string | Persons: place of birth
| `passport_number` | string | Passport number, usually for persons; in some entries it holds other details instead, such as an IMO number, a SWIFT code or an expiry note
| `address` | string | Address
| `remarks` | string | The sheet's other information column; when that is empty, the other names column, or failing that the position column
|===

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/tr-*.yaml").sort.each do |path|
  record = YAML.safe_load_file(path)
  puts [record["entity_type"], record["nationality"], record["name"]].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/tr-*.yaml")):
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    print(record["entity_type"], record["nationality"], record["name"], sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/tr.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 06:00 UTC and commits any change to `processed/`. It runs with
`--prune`, so a listing the ministry has removed is deleted here on the next
fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.4 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch tr --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/tr[`lib/ammitto/sources/tr/`].
Report data or source-list issues in
https://github.com/ammitto/data-tr/issues[this repository].
